Project 1: Custom ERP — Retail, Guyana

ERP Active — Pre-Delivery

Retail ERP Platform

Client: SaaS founder · Country: Guyana, Caribbean

A fully custom ERP system for a retail operation in Guyana. The client approached T-Mat Global after determining that off-the-shelf ERP solutions (SAP Business One, Odoo) did not fit the specific inventory and multi-location structure of their Caribbean retail business.

  • Technology: .NET 8.0, ASP.NET Core, Entity Framework, SQL Server
  • 8 core modules: inventory, sales orders, procurement, HR, payroll, accounting, POS, reporting
  • Architecture: monolith with clean module boundaries, REST API layer for future SaaS extraction
  • Deployment: Azure cloud, milestone-based delivery
  • Status: pre-delivery — active development, scheduled for staged rollout

This project represents T-Mat Global's capability in enterprise .NET development — building systems that are maintainable, documented, and deployable by the client after handoff. The contract includes a 6-month post-delivery support window and full IP assignment to the client.

Project 2: LIMS + HIMS — Healthcare Diagnostics, India

Healthcare Active — Pre-Delivery

LIMS + HIMS Platform

Client: Healthcare diagnostics company · Country: India

A combined Laboratory Information Management System (LIMS) and Hospital Information Management System (HIMS) for a healthcare diagnostics company in India. This system covers the complete diagnostic workflow — from patient registration and sample collection through result reporting and compliance documentation.

  • Technology: Java Spring Boot 3.x, Spring Security, JPA/Hibernate, MySQL, Maven
  • 8 modules: patient registration, sample tracking, test ordering, instrument integration, result entry, digital reporting, TPA billing, NABL compliance
  • Architecture: layered Spring Boot monolith, designed for microservice extraction at scale
  • Deployment: Docker + Kubernetes on Azure; cloud-native from day one
  • Status: pre-delivery — core modules built, integration and reporting in progress

This project demonstrates T-Mat Global's depth in regulated-industry software — systems where audit trails, role-based access, and compliance documentation are non-negotiable requirements, not nice-to-haves. India's NABL accreditation framework requires specific audit evidence that the system generates automatically.

What Three Projects Teach You

Running three projects simultaneously on three different stacks is operationally demanding. It requires strict context separation, consistent process discipline, and the honesty to say "we cannot take a fourth project right now" when capacity is genuinely full.

Operational insights from three simultaneous projects
  • Managed services and build projects require completely different mental models — don't try to apply sprint cadence to an on-call rotation
  • Documentation standards must be identical across projects — a new team member should be able to onboard to any project from its Notion space
  • Client communication tone differs by project type: build projects are milestone-anchored, managed services are incident/review-anchored
  • Tech stack diversity is a capability signal, not a liability — but only if each stack is staffed by people who have actually shipped on it
"The best credential is a live system. Three live systems are three credentials."
